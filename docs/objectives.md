# Objectives

The primary objective of this project was to develop and implement a reproducible bioinformatics workflow for investigating host–virus interactions using RNA sequencing data.

Specific objectives included:

* Perform quality assessment and preprocessing of RNA-seq datasets.
* Align sequencing reads to host and viral reference genomes.
* Identify and characterize virus-associated transcripts.
* Detect candidate host–viral chimeric transcripts through chimeric alignment analysis.
* Develop Python-based workflows for junction processing, filtering, and fusion sequence reconstruction.
* Visualize mapping statistics and transcriptomic patterns using Python-based analytical tools.
* Perform differential gene expression analysis using DESeq2 in R.
* Generate biological insights through volcano plots, heatmaps, and transcriptomic profiling.
* Design validation targets for experimental verification.
* Validate selected candidate events using RT-qPCR.
* Establish a reproducible and scalable workflow integrating bioinformatics and molecular biology approaches.
