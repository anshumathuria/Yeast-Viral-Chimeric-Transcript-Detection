# Tools and Technologies

## Quality Control

### FastQC

Used for assessing raw RNA-seq read quality, including per-base sequence quality, GC content, duplication levels, and adapter contamination.

---

## Sequence Alignment and Mapping

### STAR

Primary aligner used for mapping RNA-seq reads to the *Saccharomyces cerevisiae* reference genome and performing chimeric alignment analysis.

### Bowtie2

Used for mapping reads against viral reference genomes and validating candidate fusion sequences.

### SAMtools

Used for processing alignment files, extracting unmapped reads, sorting BAM files, indexing alignments, and generating mapping statistics.

---

## Programming and Data Analysis

### Python

Used for workflow automation, junction processing, fusion sequence reconstruction, data analysis, and visualization.

#### Key Libraries

* **Pandas** – Data manipulation and tabular analysis
* **NumPy** – Numerical computations
* **BioPython** – Sequence extraction and fusion sequence construction
* **Matplotlib** – Static visualizations
* **Seaborn** – Statistical data visualization
* **Plotly** – Interactive data visualization

### R

Used for transcriptomic analysis and statistical interpretation of gene expression data.

#### Key Packages

* **DESeq2** – Differential expression analysis
* **ggplot2** – Data visualization
* **pheatmap** – Heatmap generation
* **dplyr** – Data manipulation and filtering
* **EnhancedVolcano** – Volcano plot visualization

---

## Experimental Validation

### Primer3Plus

Used for designing primers targeting candidate fusion junctions identified through computational analysis.

### RT-qPCR

Used for experimental validation of selected candidate host–viral fusion events.

---

## Computing Environment

### Linux

Used for pipeline execution, workflow automation, and large-scale data processing.

### Bash

Used for automating RNA-seq processing workflows across multiple samples.

### Conda

Used for software installation, dependency management, and reproducible computational environments.

### Jupyter Notebook

Used for exploratory analysis, visualization, and workflow development.
