# Project Background

This repository showcases the computational and experimental workflow developed during my Master's thesis project focused on RNA-seq analysis, viral transcript detection, chimeric transcript identification, and differential gene expression analysis in *Saccharomyces cerevisiae*.

The project integrates multiple bioinformatics approaches including quality control, genome alignment, viral mapping, chimeric read detection, transcriptomic analysis, and RT-qPCR-based validation. Computational analyses were performed using Python, R, Linux-based workflows, and widely used bioinformatics tools such as FastQC, STAR, Bowtie2, SAMtools, BioPython, and DESeq2.

The primary objective of this repository is to demonstrate the development of a reproducible bioinformatics pipeline for processing RNA-seq data, performing host–virus interaction analysis, identifying candidate fusion events, and conducting differential expression studies.

## Skills Demonstrated

* RNA-Seq Analysis
* Transcriptomics
* Differential Expression Analysis (DESeq2)
* Viral Genomics
* Chimeric Read Detection
* Genome Alignment
* Python and R Programming
* Linux Workflow Automation
* Data Visualization
* RT-qPCR Validation
* Bioinformatics Pipeline Development
